# Fusion components (Higgsfield-twin builders)

Generated by `../scripts/fusion_build.py`. Each builder is a one-to-one twin of a Higgsfield After
Effects builder tool: same parameter names (camelCase kept), same enums, AE-style units in
(colors `{r,g,b}` 0-1 or `"#hex"`, px, seconds, percent), native Fusion `.setting` text out. Each
`<name>.setting` here is that builder at default parameters, for Fusion-page users (paste it, or drag
it into the Node Editor). Agents call the builder instead and get parameters, prefixed names and the
API-side steps a paste cannot do.

## Use

```python
# inside the Resolve MCP (run_script_unsafe)
K = "/path/to/skills/fusion-motion-design/scripts"
exec(open(K + "/fusion_kit.py").read()); exec(open(K + "/fusion_build.py").read())
cc = make_current("Testbed", "FusionSkillLab")                 # paste needs the Fusion-page comp
r = build(cc, "lower_third", title="Jane Doe", subtitle="Director", target="MediaIn1")
out = r["renamed"].get(r["info"]["output"], r["info"]["output"])   # tool to wire downstream
```

- `build(comp, name, **kw)` reads W, H, fps from the comp, pastes, then runs `info["post"]`:
  `connect` (attach to an existing tool), `reroute` (the target's consumers now read the builder's
  output, the AE "effect on the layer in place"), `expr` (expressions on existing inputs).
- Fusion extras on every builder: `W, H, fps, start` (frame), `prefix` (unique per paste; a second
  paste with the same prefix gets `_1` names), `target` (the existing tool the AE tool acted on).
- Pure call (no Resolve): `text, info = title_card(title="X")`; `info` names the output tool,
  controller, animated inputs and post steps.
- Offline: `python3 fusion_build.py --check [corpus_dir]` builds every builder x variants, parses the
  text and audits every RegID / input ID / output / SourceOp against `fusion-21.1-inputs.tsv`;
  `--components DIR` regenerates these files.
- Retime or restyle after the build by editing the controller keys (`<prefix>Ctrl`, NumberIn1 =
  reveal progress, NumberIn2 = opacity, NumberIn3 = exit) or the published group controls. Never
  address pasted splines by name (Fusion renames them); use the driven input's connected output.

## Live findings baked into the builders (2026-09-26, Resolve Studio 21.1.0.14, UHD 24 fps)

- A paste drops every `SourceOp` that names a tool outside the pasted text: wires to existing tools
  are post steps (`connect`); a group's inner tool CAN reference an outer tool pasted in the same text.
- Pasted splines are renamed `<Host><control label>` (with `NameforNumberN` set, the label: `TC_CtrlReveal`);
  a pasted Custom tool also creates `<Host>LUTIn1..4`. Address splines through the driven input.
- Loop / Pingpong / LoopRel flags go on the two keys bounding the loop only; on a middle key Fusion
  loops that first segment.
- BrightnessContrast `Low`/`High` are float levels: pixels below `Low` go negative (then Screen/Add
  subtract them). Use `ClipBlack 1` when keying highlights.
- The Glow tool's `RedScale/GreenScale/BlueScale` tint the whole output, not just the glow.
- Transform `Pivot` alone does not move the image (Size 1, Angle 0), so the Anchor Point twin also
  counter-offsets `Center`.
- Follower `Offset1` unit is about text `Size` x frame width (0.5 is about 0.85 em).
- BrightnessContrast with `Alpha 1` and `Gain` 0 -> 1 is a clean premultiplied in-place fade.
- `ConnectInput` to a pasted group returns falsy yet connects: read the wiring back.
- Caps tracking: `CharacterSpacing` 1.2 reads about +0.4 em in Fusion; 1.05-1.1 matches CSS 0.1-0.15 em.

## Mapping notes (AE -> Fusion)

- House reveal everywhere: rise 42 px @1080, scale 0.95 -> 1.00 over 0.70 s (HOUSE_SETTLE), opacity
  0.21 -> 0.33 s, 0.15 s stagger; exits IN_70 over 0.4 s. Opacity is the compositing Merge `Blend`
  (Transform has none); in-place reveals on an existing image use BrightnessContrast Gain on RGBA.
- `liquid_glass` units: frost x0.3 (AE 40 -> Fusion Blur 12, width-relative), refraction -110 ->
  0.06, magnify/saturation/tintOpacity percent -> 0-1+. Tint is a masked color plate merged at
  tintOpacity (white = the verified Lift 0.4 look).
- `expression_template` params: amplitude is px for Position/Anchor, percent for Scale/Opacity,
  degrees for Rotation; frequency Hz; period/settle/fadeIn seconds. wiggle is a deterministic sum of
  incommensurate sines (no `noise()` in SimpleExpressions); loops are spline Loop/Pingpong/LoopRel
  flags on a controller; loopContinue extrapolates the last key's velocity.
- Not matched: `ae_build_liquid_glass` SOURCE mode (`sourceLayerName`, `hideSource`) raises; build the
  pill rig and follow liquid-glass.md R10. `vibrance` is saturation (Fusion has no vibrance op).
