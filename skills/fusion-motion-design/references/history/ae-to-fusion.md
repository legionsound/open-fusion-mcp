# Transfer AE/Higgsfield principles, not contracts

> Historical (superseded 2026-09-26 by the module set in ../ and the fusion-reference skill). Kept for provenance.

AE and Fusion have different scene models. AE layers/precomps use stack order
and parenting. Fusion uses explicit dataflow and transform chains. Preserve
communication, appearance and edit intent; do not transplant API syntax.

| Intent | Candidate Fusion representation | Qualification boundary |
| --- | --- | --- |
| Layer/precomp | Named semantic subgraph; optional group/macro | Graph wiring owns ordering; macro publishing is a separate test |
| Graphic shape | Background + mask, or native shape/path chain | Probe geometry, corners and normalization |
| Editable words | TextPlus units and supported modifiers | Followers/per-character effects were not qualified in the recorded build |
| Parent motion | Explicit Transform/Transform3D chain or controller | Check pivot, local coordinates and transformed contents |
| Track matte | Explicit mask/matte branch | Verify foreground/background/mask ports and alpha |
| Effect/adjustment | Ordered, deliberately scoped effect chain | Do not assume AE compositing/effect equivalence |
| Expression/key | Native expression, scalar modifier or Bezier spline | Use the installed Fusion value/time contract |
| Physical depth | Qualified geometry, camera, lights, renderer | A mesh test does not establish all 3D capabilities |

## Transferable craft

AE/Higgsfield study informed semantic components, editable source/parent
relationships, optical centering, type hierarchy, restrained color/shadow roles,
hero/support motion, lead/follow timing, phrase-level type and actual visual QC.
Apply these to original briefs as well as reconstruction.

Do not universalize vendor defaults. Fixed web dimensions, centered headlines,
forced reveal styles, no-linear rules and automatic wiggle/glow can contradict
the brief or each other. Choose deliberate behavior and verify its rendering.
Vendor HTML/Lottie builders were AE-specific routes, not a Fusion compiler.

## When a reference is supplied

Measure its actual dimensions, cadence, duration, layout and meaningful poses.
Use obtainable source measurements for precision; do not present visual
estimates as exact sampled colors or geometry. Record stationary elements,
state changes, motion extrema and cuts separately. Compare matching semantic
events only after establishing the time mapping.

Acceptance requires appropriate source/control edits and inspected entrance,
in-between, settle, hold and exit frames. Matching node names or one still
does not prove equivalent behavior. If no reference exists, judge against the
passport's communication and craft goals, not a fabricated fidelity score.

The earlier AE benchmark document's “Fusion untested” statements describe that
earlier phase. Later Fusion evidence qualifies only the mechanisms listed in
[qualification evidence](../qualification-evidence.md); it does not retroactively
validate every AE technique.
