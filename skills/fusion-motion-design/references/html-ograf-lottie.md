# OGraf/Lottie import boundary

This is an optional format bridge, not the native authoring workflow.

The previously consulted Blackmagic Resolve 21 New Features Guide describes
OGraf/Lottie import and OGrafLoader. That is documentation-level evidence.
This session did not execute an OGraf/Lottie import or qualify its alpha,
timing, fonts, controls, persistence or platform coverage.

Before choosing this route, verify the installed release's supported file
format, loader registry ID and limits against current vendor documentation.
Then test one representative asset in the authorized target.

Choose it only for an explicitly selected existing animation whose whole-unit
editing boundary is acceptable. Keep its source and dependencies. Prefer
native Fusion when the editor must change wording, internal shapes, masks,
timing relationships or component controls directly in the graph.

Do not send raw HTML/CSS/JavaScript, React, Remotion or HyperFrames source to
Fusion. An AE vendor's HTML-to-layer workflow does not establish a Fusion
equivalent. Do not resurrect a custom HTML compiler to fill this gap.

Historical documentation pointer:
[DaVinci Resolve 21 New Features Guide](https://documents.blackmagicdesign.com/SupportNotes/DaVinci_Resolve_21_New_Features_Guide.pdf),
previously cited pages 66 and 115–116. Re-check pagination and release support
when an import task is actually requested.
