## Preferences in depth

### 3D View
- Grid: **Grid Antialiasing** (disable if hardware sorts antialiased grid lines incorrectly), **Size** (number of grid lines; unitless), **Scale** (overall grid scale factor). (p. 364)
- Perspective Views: **Near Plane/Far Plane** clip distances, minimum `0.05`; too-low Near / too-far Far loses depth precision. **Eye Separation/Convergence/Stereo Mode** set stereoscopic defaults. (p. 364-365)
- Orthographic Views: same near/far clipping concept for front/top/right/left views.
- Fit to View: **Fit Selection** (padding when F pressed with selection) and **Fit All** (padding when F pressed with nothing selected). (p. 365)
- Default Lights: ambient light used when lighting is on and no light exists in-scene; directional light position (e.g. "upper left") moves with the camera. (p. 365)

### AVI (Windows Fusion Studio only)
Default codec settings for Saver-node AVI output (overridable per-Saver): **Compressor** (available codecs, pretested at launch), **Quality** (slider, tradeoff clarity vs file size, not all codecs support it), **Key Frame Every X Frames**, **Limit Data Rate To X KB/Second**. (p. 365)

### Defaults
- **Default Animate**: modifier attached when "Animate" is chosen from a parameter's contextual menu. Default = Nothing -> Bézier spline for numeric params, Path modifier for positional params. **Number With** / **Point With** dropdowns override this per-type, listing all installed modifiers (native + third-party) valid for that parameter type. (p. 366)
- **Auto Tools** (controls automatic node insertion — directly affects scripted/automated comp building):
  - **Background**: None = standard Background tool used automatically; dropdown lets you pick any 2D/3D generator tool as the auto-inserted default instead.
  - **Merge**: None = nothing auto-inserted; Merge = standard Merge auto-inserted when connecting two tool outputs or dragging multiple clips into the Node Editor; other valid choices: Anaglyph, Channel Booleans, Dissolve.
  - **Use Merge Only When Connecting Outputs Directly**: when active, dragging multiple clips from Finder/Explorer onto the Flow does NOT auto-insert a Merge (only direct output-to-output connections do). (p. 366)
- **Global Range**: Start/End fields set the default Global Start/End frame for new compositions. (p. 367)
- **Time Code**: toggles new-comp default display between SMPTE Time Code and Feet+Frames. (p. 367)

### Flow (Node Editor behavior/appearance defaults)
- Force: **Active** (tile pictures for selected tool), **All** (tile pictures for every tile — falls back to default icon if unrendered or Show Thumbnails disabled; concatenated transforms always show default icon), **Source and Mask** (tile pictures for Source/Mask tools only). **Show Modes/Options** (icons for Disk Caching/Locked states). **Show Thumbnails** (rendered output vs default icon in tiles). (p. 367)
- Options: **Arrange to Grid** (new trees snap to grid), **Arrange to Connected** (tools snap to connected tools' axis), **Auto Arrange** (Node Editor shifts tool positions to make room on insert/auto-merge), **Show Grid**, **Auto Remove Routers** (deletes orphaned Pipe Routers when their connected tool is deleted), **Pipes Always Visible** (connection lines draw over tile tops), **Keep Tile Picture Aspect**, **Full Tile Render Indicators** (whole tile recolors as a progress bar while processing), **Show Instance Links** (green lines between Instance tools), **Navigator** (On/Off/Auto — Auto shows only when tree exceeds visible work area), **Pipe Style** (Direct = straight lines vs Orthogonal = right-angle lines), **Build Direction** (horizontal/vertical auto-layout), **Scale** (default zoom level for new comps). (p. 367-368)
- **Pipe Grab Distance**: pixel-radius slider for selecting connection lines with the pointer. (p. 368)
- **Link Grab Distance**: pixel-radius slider (0-20) for connecting/disconnecting at a node's knot; 0 = must be exactly on the knot, 20 = up to 20px away still connects. (p. 368)
- **Group Opacity**: background opacity of an expanded group in the Node Editor. (p. 369)

### Frame Format
Sets resolution/frame rate defaults for Generator tools (Background, fastnoise, Text+) and color bit depth for previews/interactive/final renders. **Color-depth settings apply to Fusion Studio only — DaVinci Resolve always renders at 32-bit float.** (p. 369)
- **Default Format** dropdown: preset resolution selected for new Generator tools; overridable per-node in the Inspector's Resolution settings.
- **Settings** (defines/edits a named format entry): **Width/Height** (pixels), **Frame Rate** (fps — drives preview/final-render rate, comp playback rate, and frame-to-timecode conversion for temporal-input tools), **Has Fields** (new Creator/Loader tools default to Fields process mode), **Film Size** (frames per foot of film, used for Feet+Frames timecode display), **Aspect Ratio** (pixel aspect ratio, two fields), **Guide 1** (left/top/right/bottom guide positions, normalized `0` to `1`, bottom-left = `0/0`, top-right = `1/1`; mismatched aspect shows an extra dotted-line guide), **Guide 2** (image aspect ratio relative to full frame width/height; >1 shrinks height relative to width, <1 grows it), **New/Copy/Delete** buttons manage format entries. (p. 369-370)
- **Color Depth**: three menus select color mode for preview / interactive / full(final) renders — 8-bit (fastest, lowest fidelity, previews only), 16-bit, 16/32-bit float (best for film/HDR, most resource-intensive). Ignored by the comp unless a Loader/Creator's own Color Depth control is set to Default. (p. 370)

### General
- Usability: **Auto Clip Browse** (File Browser auto-opens on new Loader/Saver), **New Comp on Startup** (Fusion Studio only — no effect in Resolve's Fusion page), **Summarize Load Errors** (missing-tool warnings collapse into one console summary instead of per-tool dialogs), **Save Compressed Comps** (binary vs ASCII text `.comp` — smaller files, slightly slower load, not text-editable unless re-saved uncompressed — relevant since the agent brief mentions writing `.comp` Lua-table text directly: **disable this to keep comps text-editable**). (p. 370)
- **Show Video I/O Splash** (Fusion Studio only), **Use Simplified Copy Names** (fewer underscores in copied tool names), **Show Render Settings** (Fusion Render Settings dialog shown every render start in Fusion Studio; hold Shift to suppress for that session and reuse last settings — inverted if this pref is disabled), **Mouse Wheel Affects the Window Under the Pointer** (scroll acts on hovered window instead of only the active one), **Frames Start From** (starting frame number for Loader clip/Clip-list times), **Show Color As** (Normalized 0-1 / 8-bit 0-255 / 16-bit 0-65,535 — display only, does not affect processing). (p. 371)
- Auto Save (Fusion Studio only; Resolve uses its own Project Load/Save prefs): backs up comps at a **Delay** interval (mm:ss — e.g. `10` = every 10 sec, `10:00` = every 10 min); on reopen you're offered backup vs original; opening the backup and saving overwrites the original; closing an unsaved backup deletes it harmlessly. **Save Before Render** auto-saves before any preview/final render. (p. 371-372)
- Proxy: **Update mode** default for new comps — **Selective** (default; renders only tools needed for the Display view), **All** (renders everything), **None** (no rendering). **Standard**/**Auto** sliders set default proxy-scale ratios for Proxy/Auto Proxy modes (does not affect final render quality; viewer zoom scales still reference full resolution; processing at proxy scale can differ slightly from full-res). Ratios can also be changed live by right-clicking the Prx/APrx toolbar buttons. (p. 372)

### GPU (Fusion Studio only — Resolve uses Memory and GPU prefs)
- Options: **GPU Tools** — Auto / Disable (no GPU accel for tools/plugins; Fuses may still require it) / Enable. **API** selects the GPU processing framework. **Device** selects which GPU when multiple exist: Auto prioritizes GPU but falls back to platform default; AMD/CPU options require AMD Catalyst 10.10 APP Edition driver or ATI Stream SDK 2.1+; Select lets you choose explicitly. (p. 372)
- Debugging: **Verbose Console Messages** (shows Startup Logs, Compiler Warnings, Messages), **OpenGL Sharing** (shares system RAM with GPU RAM for a larger but slower pool), **Clear Cache Files** (clears and recompiles compiled GPU kernel code). (p. 373)

### Layout (Fusion Studio only — Resolve uses Workspace > Layout Presets)
Three capture buttons: **Program Layout** (overall app window + floating windows; **Run Mode** = Maximized/Minimized/Normal; **Use the Following Position and Size**; **Create Floating Views** saves floating viewer positions), **Document Layout** (per-comp panel layout; **Recall Layout Saved In Composition** toggles whether saved comps restore their layout; **Window** menu picks which window Window Settings applies to), **Window Settings** (per-window position/size; **Automatically Open This Window**; **Run Mode**; **Use Grabbed Position and Size**). (p. 373-375)

### Loader (Fusion Studio only)
- Defaults: **Loader Depth** — Format (auto-selects bit depth from file header) vs Default (uses Frame Format preference's bit depth). (p. 375)
- Cache (disk cache — distinct from RAM cache in Memory prefs): **Disable All Local Caching**; **Cache Files from Network DiskCaches** (mirrors remote disk-cache files locally); **Enable Local Caching of Loaders** (copies files into LoaderCache path); **Cache Multi-Frame Files** (AVI/QuickTime, can be slow for large files); **Don't Cache Files from Local Disks** (skip caching for non-network files — disable if you want a fast local SSD used as cache too); **Only Files Smaller Than xxx MB** (size ceiling for caching); **Cache Path Separator Character** (default `!` — rebuilds original path under LoaderCache, e.g. `X:\Project\MyShots\Shot0815\` -> `X!Project!MyShots!Shot0815!`; using `\` instead creates real subdirectories); **If Original File Is Missing** — Fail (halts render, like default Loader) / Load Cache (uses cache with no original present) / Delete Cache (clears missing entries); **Cache Location** (mirrors the LoaderCache Path Map value); **Explore** (opens LoaderCache folder in Finder/Explorer); **Clear All Cache Files**. (p. 376)

### Memory (Fusion Studio only — Resolve uses Memory and GPU prefs)
- Caching Limits: **Limit Caching To** (% of available system RAM used for interactive tool RAM cache; lowest-priority frames purged first when limit hit); **Automatically Adjust In Low Memory Situations** (console logs cache purges); **Leave At Least X MBytes** (hard floor reserved for other applications regardless of Cache Limit — should not normally be set below 25 MB). (p. 376-377)
- Interactive Render: **Simultaneous Branching** (parallel-processes more than one tool at once; disable if memory-constrained). (p. 377)
- Final Render: **Render Slider** (number of frames rendered simultaneously); **Simultaneous Branching** (parallel branch rendering; disable to reduce memory pressure at cost of speed). (p. 377)

### Network (Fusion Studio only)
- **Submit Network Render Compositions**: Master Name + IP of the render-management machine; may be pre-filled/locked if a standalone master exists (prevents rogue masters). Set env var `FUSION_NO_MANAGER=True` to re-enable editing. (p. 378)
- General: **Make This Machine a Render Master** (accepts/manages jobs from other machines, doesn't necessarily render itself); **Allows This Machine to Be Used as a Network Slave** (accepts render jobs); **Render on All Available Machines** (ignores Render Manager groups/priorities, sends every job to every slave). (p. 378-379)
- Email Notification: **Notify Options** (Queue Completion / Job Done / Job Failure checkboxes), **Send Email to** (semicolon-separated addresses), **Override Sender Address**. (p. 379)
- Server Settings covers Clustering/Network Rendering (full detail cross-referenced to the Rendering Using Saver Nodes chapter, not in this slice). (p. 379)

### Path Maps
Virtual path aliases resolved by Fusion (e.g. `movie_x\scene_5\scan.000.cin` -> `X:\Shows\Movie_X\scene_5\scan.000.cin`), letting media move drives or comps render cross-platform without editing Loader/Saver paths. Available at Global (all new comps) and Composition (current comp only, overrides Global by name) level in Fusion Studio. **Enable Reverse Mapping of Paths Preferences**: when on, Loaders added to the Node Editor automatically use paths relative to the saved comp's location. (p. 379)

Three sections, in override order System (fixed, OS-determined) < Default (user-editable, can reference System paths) < User (new paths not in Defaults):

**System path maps** (factory, restorable): `AllData` (shared app data root), `AllDocs` (shared/public docs), `AllLUTs` (nested under Defaults, where LUTs save), `Fusion` (app install dir — e.g. `Fusion:\Help` -> wherever Fusion.exe lives), `FusionLibs` (app libraries), `Profile` (default prefs file location), `Profiles` (per-user prefs), `Programs` (Fusion Studio / Resolve location), `SystemFonts` (OS font folder used by Text+/Text 3D), `Temp` (OS temp), `UserData` (user roaming data root — Windows: `C:\Users\<user>\AppData\Roaming\`; Linux: `$HOME/Blackmagic/Fusion`; macOS: `Users/<user>/Library/Application Support/Blackmagic Design/Fusion`), `UserDocs` (user docs folder). (p. 380-381)

**Default path maps** (user-editable, nestable under System paths — e.g. `DiskCache` = `Temp:DiskCache`): `AutoSaves` (comp autosave location, tied to General prefs), `Bins` (bin metadata/pointers only — content not copied), `Brushes` (custom paintbrushes), **`Comps`** (saved compositions; default `Users/<user>/Documents/Blackmagic Design/Fusion`), `Config` (runtime config files), `Defaults` (restorable node default settings), **`DiskCache`** (Cache to Disk output location, overridable per-cache-window), `Edit templates` (macros exposed as Resolve Effects Library templates), **`Filters`** (Convolution filter files for Custom Filter node), **`Fonts`** (OS fonts folder for Text+/Text 3D and Fusion Title templates — changing this changes available fonts; does NOT affect Resolve's 5 Edit-page titles: L/R/M Lower 3rd, Scroll, Text), **`Fuses`** (Fusion Fuses plugin folder), **`FusionTemplates`** (macros exposed in Fusion Studio's own Effects Library Templates category), `Guides` (custom viewer guide overlays — see Bins section above), `Help` (Fusion Studio PDF docs), `Layouts` (custom window layouts), `Libraries` (custom Effects Library support files), **`LoaderCache`** (local cache drive for network Loader files), **`LuaModules`** (Lua scripting module location), **`LUTs`** (Look Up Tables folder), **`Macros`** (user macros — appear in Effects Library Macros category and right-click Edit Macro menu), `Plugins` (per-user OpenFX plugins, not shared), `Previews` (legacy flipbook file-sequence previews), `Queues` (Render Manager list location), **`Scripts`** (Lua/Python script location — further subdivided by script type: tool/node scripts, comp scripts, etc.), **`Settings`** (custom saved node settings), `Stamps` (bin preview-movie location, outdated since Studio Player), **`Templates`** (macros here appear in the Effects Library's Templates category — in Fusion Studio, this category is hidden until a macro is saved into it), `Thumbs` (bin clip thumbnails), `UserPaths` (studio/facility-specific tools on a central server). (p. 381-382)

**User path maps**: any new path not already in Defaults, e.g. `Comp` = folder of the currently open composition (enables relative-path Loaders when media sits alongside the comp file). (p. 382)

- Modify a System or Default map: select it, click the folder icon, edit the `From:`/`To:` fields.
- Create a User map: click **New**, fill `From:`/`To:`.
- Delete: select a **User-created** map (only), click **Delete** — System and Default maps cannot be deleted.
- **Nesting**: a path map can reference another, e.g. define `Episode` = `MyDrive\Projects\Episode1`, then `Renders` = `Episode\Renders_v1` and `Stills` = `Episode\Stills_v1`. (p. 382)

### Preview (Fusion Studio only — Resolve uses Media Storage's Scratch Disk)
**Render Previews Using Proxy Scaling** (scales down before render for speed vs full-size-then-scale-down), **Skip Frames to Maintain Apparent Framerate** (drops frames during Flipbook/sequence playback to hold fps), **Show Previews for Active Loaders** / **Show Previews for Active Savers** (playback controls under Inspector), **Display File Sequences On** (target viewer/monitor for interactive playback, sequence playback, and bin scrubbing). (p. 383)

### QuickTime (Fusion Studio, macOS only)
Default codec for Saver QuickTime output: **Compressor** (pretested codec list), **Quality** (slider), **Key Frame Every X Frames**, **Limit Data Rate To X KB/Second**. (Same structure as AVI prefs above.) (p. 384)

### Script
- Login (controls external/remote script execution, not in-app scripts): **No Login Required to Execute Script**; **Specify Custom Login** (username+password required for command-line or remote-Fusion-control scripts, e.g. via FusionScript — in-app scripts are exempt); **Use Windows Login Validation** (Windows only — verifies OS credentials before running). (p. 385)
- Options: **Script Editor** (external editor launched by Scripts > Edit). (p. 385)
- **Python Version**: selects which Python version Fusion uses for scripts (two options presented; specific versions not enumerated in this slice). (p. 385)

### Spline Editor
Affects only the Spline Editor panel (not viewer polygon/path tools). **Independent Handles** (In/Out Bezier handles move independently on new keys), **Follow Active** (editor tracks the active tool), **Show Key Markers** (colored triangles on the Time Ruler matching spline colors), **Show Tips** (tooltips), **Autosnap Points** (snap moved points to fields/frames vs free move), **Guides** (snap points to guides), **Autosnap Guides** (snap guides to fields/frames), **Autoscale** (keep graph scale fixed vs auto-rescale on content change), **Scroll**/**Fit** (scale-submenu options: scroll to show points vs zoom-to-fit). LUT View has its own copies of Independent Handles / Show Key Markers / Show Tips. All are duplicated in the Spline Editor's own right-click Options/Show/Scale submenus. (p. 386-387)

### Splines
Governs animation-spline behavior across the whole app (not just the Spline Editor):
- **Autosmooth**: auto-smooths newly created points/keys, selectable per spline type — animation splines, B-Splines, polyline mattes, LUTs, paths, meshes. (p. 387)
- **B-Spline Modifier Degree**: Cubic (2 control points between anchors) vs Quadratic (1 control point) for animation B-Splines. **B-Spline Polyline Degree**: same concept, for mask B-Splines. (p. 388)
- **Tracker Path Points Visibility**: Show / Hide / Show on hover (**default**). **Tracker Path**: default tracker path type is Bézier; alternatives are B-Spline or XY Spline. (p. 388)
- **Polyline Edit Mode on Done**: after finishing a polyline draw, whether it enters modify-existing-points mode or modify-and-add-new-points mode. (p. 388)
- **Onion Skinning**: number of frames shown while rotoscoping; adjustable to show only prior frames, only after, or split between both. (p. 388)

### Timeline (Keyframes Editor / Spline Editor filters and defaults)
- **Filter** / **Filter to Use**: Filter populates/edits the tool-visibility hierarchy for a named filter; Filter to Use sets which filter is the default in the Keyframes Editor Options menu. New/Copy/Delete manage filters; only checked tools appear in the Keyframes/Spline Editor when a filter is active. (p. 388-389)
- **Timeline Options** (checkboxes mirror Timeline/Keyframes Editor toolbar buttons, set default state for new comps): **Autosnap Points**, **Guides** (snap to placed guides), **Autosnap Guides**, **Autoscale** (fixed graph scale) vs the alternative Scroll (pan to show points) or Fit (zoom to fit) behavior, **Tools Display Mode** (default sort order of tools in Keyframes Editor — overridable live via the Sort order menu). (p. 389)

### Tweaks (Fusion Studio only — network rendering + graphics-hardware fine-tuning)
- Network: **Maximum Missed Heartbeats** (checks before dropping a Render node), **Heartbeat Interval** (time between checks), **Load Composition Timeout**, **Last Slave Restart Timeout**. (p. 389-390)
- File I/O: **I/O Canceling** (lets the OS cancel queued I/O ops when the requesting function stops — improves responsiveness for network loads, especially seek-heavy formats like TIFF; untested across all hardware/OS, test before relying on it), **Enable Direct Reads** (more efficient large-contiguous-read method; OS-dependent, may behave unpredictably), **Read Ahead Buffers** (slider — number of 64K read-ahead buffers; more = more efficient disk loading but less interactive responsiveness to disk-access changes). (p. 390)
- Area Sampling (RAM vs speed tradeoff for Merge/Transform tools): **Automatic Memory Usage** (default on — Fusion auto-detects available RAM and picks a proxy level; lower RAM -> higher internal proxy level -> longer render, no quality loss, only time cost; for >4K trees, consider manual override to reserve RAM). **Pre-Calc Proxy Level** slider (enabled only when Automatic Memory Usage is off; higher = less RAM, longer render). (p. 390-391)
- OpenGL (3D compositing via Renderer 3D node): **Disable View LUT Shaders** (forces CPU-based full-accuracy LUT processing — try if OpenGL-shader View LUTs look wrong); **Use Float16 Textures** (uploads int16/float32 images as float16 to viewer if hardware supports it — can improve playback); **Texture Depth** — Auto (recommended, best balance), int8 (faster, less View-LUT correction range), Native (no conversion); **Image Overlay** (translucent overlay for Merge/Transform controls outside image bounds) — None (never shown, can speed up display by reducing background renders), Outside (only out-of-bounds areas), All (all selected tools' overlays); **Smooth Resize** (disables smooth viewer resize for float images on hardware that filters float textures poorly — try `flt16` or `int` settings if float smooth-resize misbehaves). (p. 391-392)
- **Auto Detect Graphics Memory (MB)**: manual override for how much VRAM Fusion claims, useful when other OpenGL apps (e.g. 3D software) run concurrently — too low/high can cause performance loss or data loss. **Use 10-10-10-2 Framebuffer**: enables 30-bit color viewer rendering (10 bits/primary vs 8) on supporting hardware/monitors (Nvidia Quadro/AMD Radeon Pro, some GeForce/Radeon) — reduces banding on deep/3D renders. (p. 392)

### User Interface
- Appearance: **Use Gray Background Interface** (lighter neutral gray panel background). (p. 392)
- Controls: **Auto Control Open** (double-click header to reveal params vs auto-reveal on select), **Auto Control Hide** (only active/red-outlined tool's params visible), **Auto Control Close Tools** (only active tool shown in Inspector, closing others — no effect if Auto Control Hide is on), **Auto Control Close Modifiers** (only one modifier's params shown per active node), **Auto Control Advance** (Tab/Return advances focus to next Inspector field vs Return accepts value and stays put; Tab always advances), **Show Controls for Selected** (default on — shows params for active + all selected tools; off = active tool only), **Combined Color Wheel** (one switchable wheel for master/shadow/midtone/highlight vs four simultaneous wheels in Color Corrector), **Gamma Aware Color Controls** (for uncolor-managed Rec.709 work: removes gamma, applies correction linearly, reapplies gamma — set Gamma value to `2.4` for Rec.709; set to Off or `1.0` in a color-managed linear project; auto-set from image metadata when mixed color spaces are present), **Grab Distance** (slider `1`-`10`, default `5` — active-area radius around pointer for selecting path/spline points; smaller = more precise required). (p. 393)
- Touch Scrolling and Mouse Wheel: modifier-key configuration for trackpad/wheel pan and zoom (specific bindings not detailed in this slice). (p. 393)

### Variables Map
Custom variables usable in expressions and Saver paths, definable at Global (all comps) or Composition (per-comp) level; can reference expressions and other variables. Reference syntax: `fu.vars.[name]` (Global) / `comp.vars.[name]` (Composition) in expressions. In a Saver's Filename field, type `%{name}` to list available categories including custom variables, clip metadata, and (Fusion page only) Resolve metadata. Metadata variable syntax in Saver: `%{metadata.metadataname}`; Resolve metadata syntax: `%{resolve:Resolve Metadata}`. Upstream clip metadata in expressions: `fu.vars.metadata.[name]` or `comp.vars.metadata.[name]`. Resolve metadata in expressions (Fusion page only): `fu.vars.resolve["Name"]`, e.g. `fu.vars.resolve["Timeline Name"]`. (p. 394-395)

### Video Monitoring (Fusion Studio only — Resolve routes this through its own preferences)
Configures Blackmagic DeckLink/UltraStudio hardware output (display only — does not affect rendered file output). **Output HDR over HDMI**: Auto (detects HDR image values, no effect on non-HDR) / Always (forces HDR at all times, useful for A/B checking) / off; when Auto or Always, set the target "nit" (cd/m2) peak-luminance level to match the connected HDR display. Stereo Mode: Mono / Auto (detect stacking) / Vstack (left top, right bottom) / Hstack (left/right side by side); **Swap eyes** checkbox if reversed. (p. 395-396)

### View
Per-viewer settings selected via **Settings for View** dropdown. **Saved View Settings** list (create from viewer's contextual menu; Rename/Delete here). **Control Colors** (active/inactive onscreen control color). **Color Picking Area Size** (width/height in pixels sampled by the viewer Color Picker). **Displayed Depth Range** (normalization range for Z-channel viewing). **Fit Margin** (padding when Fit is pressed/selected). **Display LUT Plugins** (available display LUTs; select the default). (p. 396-397)

### VR Headsets
**API**: Disabled / Auto (detect plugged-in headset) / Oculus / OpenVR (HTC Vive etc.). **360° Video Format**: Auto (detect from metadata/aspect) / VCross, HCross (6 cube faces in a cross layout, forward face centered, 3:4 or 4:3 image) / VStrip, HStrip (6 cube faces in a line, ordered Left/Right/Up/Down/Back/Front i.e. +X/-X/+Y/-Y/+Z/-Z, 1:6 or 6:1 image) / LatLong (single 2:1 equirectangular image). **Enable Mirror Window** (shows headset user's live view in a window). Stereo Mode: Mono / Auto / Vstack / Hstack / Swap Eyes (same semantics as Video Monitoring). 3D: **Light** — Disabled / Auto (detect scene lighting) / On (force on). **Sort Method** — Z buffer (fast OpenGL sort), Quick Sort (better transparency), Full Sort (most robust transparency); **Shadows** on/off; **Show Matte Objects** visible/invisible. (p. 397-399)

Manages Bin Server users/permissions. **Users List** with Add/Remove. **User** field (try "Guest" with no password if unknown). **Password** field. **Permissions**: Read (view only), Create (make new bins), Admin (full control), Modify (edit existing bins), Delete (remove bins). (p. 399-400)

### Bins/Settings (Fusion Studio only)
**Stamp Quality** (% compression slider for Stamp thumbnails — higher = better quality, more space). **Stamp Format** (compressed vs uncompressed thumbnail storage). **Open Bins on Startup** (auto-opens Bins window on launch). **Checker Underlay** (checkerboard background behind alpha-channel clips vs plain gray matching the Bin window). (p. 401-402)

**Flow Format**: Loader Per Clip (one Loader per EDL clip) / A-B Roll (auto-builds a Dissolve node tree) / Loader Per Transition (single Loader with a Clip list representing the whole EDL). **Use Shot Names**: when checked, locates footage using shot names stored in the EDL rather than by path. (p. 402-403)

## Gotchas and non-obvious behavior
- Composition-level preferences (Fusion Studio) silently override Global preferences of the same name for the currently open comp only — an agent editing "the" preferences must know whether it's touching Global or Composition scope. (p. 360)
- A large fraction of Preferences categories do nothing in DaVinci Resolve's Fusion page (GPU, Memory, Network, Layout, Loader, Preview, Video Monitoring, Bins/*, AVI, QuickTime) — always check the "Fusion Studio Only" qualifier before assuming a setting applies inside Resolve. (p. 361-363)
- Color-depth choices in Frame Format preferences are cosmetic/ignored inside DaVinci Resolve — final render there is always 32-bit float. (p. 369, 370)
- `Auto Tools > Merge` and `Background` determine whether connecting two nodes or dragging clips auto-inserts a Merge/Background — this is a hidden dependency for any script that assumes a Merge always appears when two outputs are wired together. "Use Merge Only When Connecting Outputs Directly" specifically suppresses auto-Merge for multi-clip drag-and-drop from the OS file browser (but not for direct output connections). (p. 366)
- "Save Compressed Comps" (General prefs) makes `.comp` files binary, not text-editable — must be disabled (or the comp re-saved uncompressed) for the "paste Lua-table `.comp` text" workflow the brief describes to work. (p. 370)
- Loader Depth "Format" vs "Default": Format reads the file header to pick bit depth; Default forces the Frame Format preference's bit depth regardless of source file — a mismatch here is a common source of unexpected color/bit-depth behavior on ingest. (p. 375)
- LoaderCache and DiskCache are two different caching systems: LoaderCache (Loader preferences) mirrors source *media* locally for network/large files; DiskCache (Path Maps, used by "Cache to Disk") stores *rendered intermediate results*. Memory preferences' RAM cache is a third, separate system for interactive playback. Don't conflate the three. (p. 376-377)
- Path Map override order is System < Default < User/Composition, and only User-created maps can be deleted — attempting to delete a System or Default map is a no-op/blocked. (p. 382)
- Reverse Path Mapping ("Enable Reverse Mapping of Paths Preferences") changes how NEW Loaders are added — they'll use paths relative to the saved comp automatically. If this is off, Loader paths are absolute even when a relative Comp path map exists. (p. 379)
- `Fonts` path map does not affect DaVinci Resolve's five built-in Edit-page titles (L/R/M Lower 3rd, Scroll, Text) — only Text+/Text 3D/Fusion Title templates. (p. 381)
- Script login settings (No Login Required / Specify Custom Login / Use Windows Login Validation) only gate **external/remote** script execution (command line, FusionScript remote control) — scripts run from inside the Fusion UI are never blocked by this. An agent driving Fusion externally via the scripting API needs to check this setting. (p. 385)
- Preferences file location can be silently redirected/locked by environment variables the agent won't see in the UI: `FUSION_PROFILE_DIR` (base folder for the Profiles dir; falls back to `AllData:\Profiles` if it can't create the path), `FUSION_PROFILE` (per-user subfolder name, e.g. `jane`), `FUSION_MasterPrefs` (semicolon-separated list of site-wide prefs files that seed but don't get overwritten by local prefs), and critically `Locked = true` in a master prefs file makes ALL its settings uneditable by the user — an agent that can't reproduce an expected preference change should check for a locked master prefs file before assuming a scripting/API bug. (p. 404-405)
- `FUSION_NO_MANAGER=True` is required to re-enable manual editing of the Network preferences' render-master Name/IP fields when a studio has a standalone render master configured (otherwise those fields are pre-filled and locked). (p. 378)
- Bin server permissions/passwords are stored in **plain text** inside the bin document itself — a real security consideration for any studio automation touching bin files directly. (p. 393-394 / p. 343 duplicate note)
- Grab Distance (User Interface prefs, path/spline point selection, 1-10 default 5) is a different control from Link Grab Distance (Flow prefs, 0-20, for node-knot connections) and Pipe Grab Distance (Flow prefs, connection-line selection) — three separately-tunable "how close do I need to click" settings that are easy to confuse. (p. 368, 393)
