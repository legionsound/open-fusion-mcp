## Recipes / workflows
1. **Make a comp's `.comp` file text-editable for direct Lua-table authoring**: Preferences > Global > Default Settings > General > uncheck "Save Compressed Comps". Existing compressed comps must be re-saved once this is off to become text-editable. (p. 370)
2. **Point Fusion at a custom Scripts location** (for automation/tooling deployment): Preferences > Global > Default Settings > Path Map > Default section > select `Scripts` > click the folder icon > set `To:` path. Nest under an existing path map (e.g. a studio `UserPaths` map) if you want it to move with a facility-wide relocation. (p. 379-382)
3. **Guarantee a Merge is inserted when two node outputs are wired together in an automation script**: verify Preferences > Global > Default Settings > Defaults > Auto Tools > Merge is NOT set to "None" before assuming the connection auto-creates a Merge tool; if scripting via `ConnectInput`, this preference is irrelevant (auto-merge only fires for interactive drag/connect actions, not direct API calls) — (inference, not explicit in this slice, but implied by "connecting the outputs of two tools **or dragging** multiple clips"). (p. 366)
4. **Add a network Bin Server**: Preferences > Global > Bins > Servers > Add > fill Server (name/IP), User, Password, Library (bin name — e.g. per-project), Application (optional custom serving program) > Save > open Bins window to test the connection (first open = first connection test; failures show "(unavailable)" next to the bin name in the sidebar, with no hard limit on number of bins). (p. 342-343, 400-401)
5. **Create/attach a custom viewer guide overlay**: write an XML `.guide` file (Guide { Name=, Elements={ HLine/VLine/Rectangle {...} } }) and save it into the Path Map `Guides` folder, then in the Studio Player right-click one of the three Guide buttons and select it from the list. (p. 340-342, 625-636 region)
6. **Fusion Connect manual round-trip (fastest, most control, Fusion need not be on the Avid machine)**: apply the AVX plug-in in Avid's Effects Palette -> Export Clip -> Edit Effect (creates comp, launches Fusion if local) -> edit and save the comp in Fusion -> render the comp in Fusion (can continue editing in Avid meanwhile) -> render the clip in Avid (optional but recommended). (p. 350-351)
7. **Recover from "my Fusion preference change isn't sticking"**: check for `FUSION_MasterPrefs` env var pointing at one or more site prefs files, and inspect those files for `Locked = true` in the main table — locked master settings cannot be changed by the user or (implicitly) by scripted preference writes. (p. 405)

## Scripting and automation hooks
- Expression variable access: `fu.vars.[name]` (Global Variables Map entry), `comp.vars.[name]` (Composition Variables Map entry), `fu.vars.metadata.[name]` / `comp.vars.metadata.[name]` (upstream clip metadata), `fu.vars.resolve["Name"]` e.g. `fu.vars.resolve["Timeline Name"]` (Resolve timeline metadata, Fusion page only). (p. 394-395)
- Saver filename tokens: `%{name}` (lists available variable/metadata categories when typed in the Filename field), `%{metadata.metadataname}` (clip metadata), `%{resolve:Resolve Metadata}` (Resolve metadata, Fusion page only). (p. 394-395)
- Guide file format (`.guide`, XML-like Lua-table text), extension and required location: see Path Map `Guides` and the Custom Guide Format block above. Elements: `HLine{Y1=}`, `VLine{X1=}`, `Rectangle{X1=,Y1=,X2=,Y2=}`; attributes `Pattern` (4-hex-digit dash pattern), `Color`/`FillColor` (8-hex-digit RGBA, e.g. `#FF000000`=pure red, `#00FF0000`=pure lime green), `FillMode` (`None`|`Inside`|`Outside`). (p. 340-342)
- Preferences are stored on disk as `Fusion.prefs`, a plain Lua-table text format, under the Path Map location `AllData:\Profiles` by default (or wherever `FUSION_PROFILE_DIR` points). (p. 404)
- Environment variables referenced in this slice: `FUSION_PROFILE_DIR` (base folder containing the `Profiles` folder — created if missing, falls back to `AllData:\Profiles` if creation fails), `FUSION_PROFILE` (per-user profile subfolder name, e.g. `jane`, combined with `FUSION_PROFILE_DIR`), `FUSION_MasterPrefs` (semicolon-separated path(s) to site-wide prefs files Fusion reads but never writes to; use with `Locked = true` in the file's main table to force-override user prefs), `FUSION_NO_MANAGER` (set to `True` to unlock the Network prefs' render-master Name/IP fields when a standalone master already exists), and Fusion Connect's own `CONNECT_PROJECT`, `CONNECT_DRIVE`, `CONNECT_SEQUENCE_PATH`, `CONNECT_CLIP_PATH`, `CONNECT_OUT_PATH`, `CONNECT_COMP_PATH` (Windows: system-wide via Control Panel "env" system-variables link, user-scope via the "your account" link; macOS: user scope in `~/.bash_profile`, system scope in `/etc/profile`; user variables always win over system on name collision). (p. 357, 378, 404-405)
- Named Path Maps usable in Loader/Saver paths and scripting (`Comp:`, `Scripts:`, `Macros:`, `Templates:`, `FusionTemplates:`, `Fuses:`, `LUTs:`, `LuaModules:`, `Fonts:`, `DiskCache:`, `LoaderCache:`, `Settings:`, `Filters:`, `UserPaths:`, plus System maps `Fusion:`, `FusionLibs:`, `Profile:`, `Profiles:`, `Programs:`, `SystemFonts:`, `Temp:`, `UserData:`, `UserDocs:`, `AllData:`, `AllDocs:`, `AllLUTs:`) — full list and semantics under the Path Maps section above. Example syntax shown in the manual: `Fusion:\Help` expands relative to wherever the Fusion app is installed. (p. 380-382)
- Keyboard shortcut for opening Bins: **Command-B** (macOS notation given in manual). (p. 327)
- Hotkey customization: View menu > Customize HotKeys opens the Hotkey Manager (Fusion Studio only); New/Edit opens the Edit Hotkey dialog specifying key combo, Action (pressed/repeated/released), Name, Short Name, and Arguments. Shortcuts are scoped to the active/focused region (Node Editor, Viewer, Spline Editor, etc.) — e.g. Command-F means "Fit" in a Viewer, "Find" in the Flow view, and "Fit splines to window" in the Spline Editor. (p. 403-404)
