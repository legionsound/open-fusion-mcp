## Scripting and automation hooks

- **Toolbar abbreviations** (usable in the Select Tool dialog and as scripting references — verbatim from the manual's bracketed names): Blur nodes — `Blur`, `Dfo` (Defocus), `DrBl` (Directional Blur), `Glo` (Glow), `Shrp` (Sharpen), `SGlo` (Soft Glow), `USM` (Unsharp Mask), `VBL` (Vari Blur), `VMB` (Vector Motion Blur). Color nodes — `ATr` (ACES Transform), `CrA` (Chromatic Adaptation), `CST` (Color Space Transform), `GML` (Gamut Limiter), `GMp` (Gamut Mapping), `CAR` (Chromatic Aberration Removal), `AG` (Auto Gain), `BC` (Brightness Contrast), `Bol` (Channel Booleans — 2D; distinct from 3D's `3Bol`), `CC` (Color Corrector), `CCv` (Color Curves), `Clr` (Color Gain), `CMx` (Color Matrix), `CS` (Color Space), `CpA` (Copy Aux), `Gmt` (Gamut), `HCv` (Hue Curves), `OCT` (OCIO CDL Transform), `OCS` (OCIO Color Space), `OCD` (OCIO Display), `OCF` (OCIO File Transform), `SCv` (Set Canvas Color), `WB` (White Balance). Composite nodes — `DX` (Dissolve), `Mrg` (Merge), `MMrg` (MultiMerge). Deep Image nodes — `dCC` (dColorCorrector), `dCr` (dCrop), `DTI` (Deep to Image), `DTP` (Deep to Points), `dHld` (dHoldout), `dMg` (dMerge), `dRc` (dRecolor), `dRz` (dResize), `dXF` (dTransform), `ITD` (Image to Deep). Deep Pixel nodes — `SSAO` (Ambient Occlusion), `DBl` (Depth Blur), `Fog` (Fog), `Shd` (Shader), `Txr` (Texture).
- **Merge Operator-mode math** (for scripted expressions or manual `.comp`/`.setting` edits), general form `(fg * x) + (bg * y)`: Over `x=1, y=1-af`; In `x=ab, y=0`; Held Out `x=1-ab, y=0`; Atop `x=ab, y=1-af`; XOr `x=1-ab, y=1-af`; Conjoint `x=1, y=x+y(1-af)/ab` (if af>ab); Disjoint `x=x+y(1-af)/ab, y=x+y` (if af+ab<1); Mask `x=x*af, y=0`; Stencil `x=x*(1-af), y=0`; Under `x=y, y=x*(1-af)`. HDR-safe Apply Modes: Hypotenuse `Out = sqrt(Fc*Fc + Bc*Bc)`; Geometric `Out = 2*Fc*Bc / (Fc+Bc)`.
- **Color Matrix identity/expressions**: default matrix is `[R out]=1*[Rin]+0*[Gin]+0*[Bin]+0*[Ain]+0` (and analogous rows for G/B/A) — the 5th "Add" column/row is a literal additive offset per output channel, useful for hand-writing `.setting`/`.comp` Lua tables that construct a ColorMatrix tool's Matrix input directly.
- **Brightness/Contrast and Color Corrector core formulas** (safe to reuse in expressions or custom tools): Gain = `pixel * gain`; Lift = `pixel + lift * (1 - pixel)`; Low/High normalize = `(input - low) / (high - low)`.
- **DCI-P3 as a Custom Gamut** (for scripting a Gamut node's Custom values without loading a preset): Red Primary (0.68, 0.32), Green Primary (0.265, 0.69), Blue Primary (0.15, 0.06), White Point (0.314, 0.351), Gamma 2.6, Linear Limit 0.0313 (SMPTE-431-2).
- **OCIO config resolution order**: environment variable `OCIO` (path to a `.ocio` file) takes precedence if set; otherwise Fusion falls back to `DefaultConfig.ocio` in Fusion's own LUTs directory. Sample OCIO configs: https://opencolorio.readthedocs.io/en/latest/configurations/_index.html#configurations.
- **Import Transform file types** (Deep to Points Transform tab, and presumably other 3D-transform-import controls): `.lws` (LightWave Scene), `.ase` (Max Scene), `.ma` (Maya Ascii Scene) — imports transform data only, not geometry/lights/cameras (use File > FBX Import for those).
- **Onscreen 3D transform keyboard shortcuts** (Deep to Points and other 3D tools): `Q` = translate mode, `W` = rotate mode, `E` = scale mode.
- **Merge/Composite match-move shortcut**: `Command-T` (Mac) / `Ctrl-T` (Win/Linux) swaps a node's Foreground and Background connections in place — used to reach Merge Operator modes not directly listed (Under, In, Held In, Below) by swapping inputs and picking the corresponding listed mode.
- **Cache to Disk** (Deep Image nodes): right-click any deep-compositing node → Cache to Disk → choose a save path → OK, to bake an expensive deep composite and reduce live recompute cost.
- **Scripts tab**: every node in Fusion (all categories in this slice) exposes 3 scripting edit-box fields on its Settings tab that execute when the tool renders — consult Fusion's scripting documentation for the callback details (not enumerated in this slice).
