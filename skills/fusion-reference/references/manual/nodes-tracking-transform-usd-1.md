# Fusion 21.1 — Tracking, Transform, and USD Nodes
Scope: manual pages 1572-1715 (Chapters 60-62: Tracking Nodes, Transform Nodes, USD Nodes). Use when: setting up match-move/stabilization tracking (Camera Tracker, Planar Tracker, Surface Tracker, Tracker), building 2D/3D spatial transforms (Transform, Scale, Resize, Crop, Letterbox, DVE, Camera Shake, Planar Transform), or building/editing a USD 3D scene in Fusion (the `u`-prefixed node family).

## Mental model
- **Three families, three jobs.** Tracking nodes *analyze* motion and publish data (position/angle/size splines, or 4x4 matrices). Transform nodes *apply* a spatial transform to a 2D image. USD nodes build/render a USD scene graph inside the 2D tree.
- **Concatenation vs. resampling.** Transform, Camera Shake, and Tracker Match Move concatenate their matrix with adjacent transform-type nodes by default, so a chain of moves resamples the image once, at the end (higher quality). **Flatten Transform** (named "Flatten Transformation" on Tracker) breaks this: the node still concatenates transforms coming *in*, but won't concatenate its own transform with the node downstream, forcing an immediate resample.
- **Resolution-changing vs. -preserving.** Crop, Resize, Scale, Letterbox actually change pixel dimensions (manual warns against animating them for this reason). Transform, DVE, Camera Shake do not — Transform is "the tool most often used to scale, move, and rotate a clip" specifically because it preserves resolution (p. 1648).
- **Normalized 0-1 coordinates.** Position/size controls are stored as 0-1 fractions of image width/height for resolution independence. Transform's **Reference Size** re-displays these as pixel values for convenience only — the stored/scripted/published value stays normalized (p. 1651-1652).
- **Filter Method family** (reused by Camera Shake, Letterbox, Resize, Scale, Transform, Tracker Match Move): Box, Linear, Quadratic, Cubic, Catmull-Rom, Gaussian, Mitchell, Lanczos, Sinc, Bessel — increasing quality/cost roughly in that order; Sinc/Bessel add a **Window Method** (Hanning, Hamming, Blackman, Kaiser) to bound their infinite support. Most filters matter only when enlarging; when shrinking, Bi-Linear is common but Catmull-Rom sharpens detail on downscale. Documented once here, not repeated per node.
- **Edges family**: naming varies by node (Canvas/Black Edges, Wrap, Duplicate, Mirror) for how revealed/off-frame pixels render; a separate **Clipping Mode** (Domain keeps off-frame data for a later node; Frame discards it) appears on Crop, Planar Tracker, Tracker.
- **Settings-tab Common Controls** (Blend, Process When Blend Is 0.0, RGBA channel buttons, Apply Mask Inverted, Multiply by Mask, Use Object/Material + Correct Edges + ID sliders, Motion Blur group, Use GPU, Hide Incoming Connections, Comments, Scripts) are identical on every Tracking/Transform node — documented once under Common Controls.
- **Tracking data is published, not just piped downstream.** A Tracker/Camera Tracker/Planar Tracker need not connect to anything — outputs are exposed on each target parameter's **Connect To** menu, so one tracker can drive any parameter anywhere in the comp.
- **Planar Tracker does not persist point-level tracking data across save/reload** (unlike Camera Tracker) — finish planar tracking in one session; only the final Track/Stable Track splines (4x4 matrices) survive reliably.
- **USD assembly pattern:** source nodes (uLoader, uShape, uCamera, uLights, uImage Plane, uDuplicate, uProjector, override nodes) feed **uMerge** (which also parents — transforming uMerge moves everything feeding it), and every branch terminates in **uRenderer** (flattens 3D to 2D) (p. 1656, 1680).
- **Prim Selection / USD Scene Tree dialog** ("Pick" button) is the shared targeting mechanism for uCamera/uLight Override Selection, uVisibility, uVariant, uReplaceMaterial, uTransform. Cmd-click toggles multi-select, Shift-click range-selects (p. 1657).
- **Texture vs. Light projection mode** (uProjector, uCamera): Light mode adds RGB as diffuse/specular light and ignores the projected image's Alpha (can't clip geometry with it); Texture mode, paired with a **uCatcher** material on the receiver, respects Alpha and can drive non-diffuse channels (specular, bump, reflection) (p. 1661-1662, 1678-1679).

## Tracking Nodes

### Camera Tracker (CTra)
Solves a live-action camera's 3D motion path and a 3D point cloud, for compositing 3D elements into 2D footage. (p. 1573)
- Inputs: **Background** (orange, required); **Occlusion Mask** (white — white pixels excluded from tracking, e.g. a moving person).
- Tabs: Track (setup/auto-track), Camera (lens/gate specs), Solve (run/clean/align), Export (build 3D nodes), Options (overlay display).
- Track tab: **Auto Track** (auto-detect+track; auto-terminates on high error); **Detection Threshold** / **Minimum Feature Separation** (density/spread of auto tracks — smaller separation = more tracks, longer solve); **Track Channel** (R/G/B/luma); **Track Range** (Global/Render/Valid/Custom); **Bidirectional Tracking** (extends tracks backward too — recommended on, longer tracks solve better); **Gutter Size** (% of pattern size; tracks entering this edge margin auto-terminate; default 100%, so a 0.04 pattern → 0.04 gutter); **New Track Defaults > Tracker** — all trackers use Optical Flow refined by Fusion/Planar Tracker; default **TRS** (Translation/Rotation/Scale) recommended, Affine/Perspective need large patterns; sub-options **Close Tracks When Track Error Exceeds** and **Solve Weight** (advanced, rarely changed).
- Camera tab: **Focal Length** (known value, or seed if Refine Focal Length is on); **Film Gate** preset or manual **Aperture Width/Height** (inches); **Resolution Gate Fit** (Width/Height/Inside/Outside/Stretched); **Center Point** (default 0.5, 0.5); **Use Source Pixel Aspect** (else manual Pixel X/Y); **Auto Camera Planes** (auto-fits near/far to point cloud each solve; disable if the solver flings stray points far out).
- Solve tab: **Solve** runs solver; **Delete** clears only camera+point cloud (Track tab's **Reset** clears everything including tracks). **Average Solve Error** — **<1.0 px generally good, 0.6-0.8 px excellent** (p. 1578). **Clean Tracks by Filter** / **Clean Foreground Tracks** (+ **Foreground Threshold**) select bad/fast-object tracks, optionally auto-deleted via **Auto Delete Tracks by Filter** / **Auto Delete Foreground Tracks**. **Accept Solve Error** — if exceeded, solver sweeps focal length to compensate; fails if it can't (fix: correct focal length, or clean noisy tracks and re-solve). **Auto Select Seed Frames** (auto-pick two far-apart, high-overlap reference frames) vs manual **Seed 1/Seed 2** sliders (values found in prior solve's Solve Summary). **Refine Focal Length**. **Enable Lens Parameter** exposes **Refine Center Point** (usually off) and **Refine Lens Parameters**: Radial Quadratic / Radial Quartic / Radial & Tangential / Division Quadratic / Division Quartic (each solving Lower/Higher Order Radial Distortion, +Tangential X/Y where applicable); tangential distortion is rare outside cheap consumer cameras, leave disabled. **Track Filtering**: Minimum Track Length (5-10 frames typical, ~3 for fast rotation), Maximum Track Error, Maximum Solve Error (deleting worst ~20% is a common quick win), plus Select Tracks Satisfying Filters / Auto Select Tracks While Dragging Sliders. **Operations on Selected Tracks**: Delete, Trim Previous, Trim Next, Rename, Set Color, Export Flag (point-cloud export per track), Solve Weight (set 0 to keep a locator without influencing the solve). **3D Scene Transform**: Aligned/Unaligned toggle; while Unaligned, **Set from Selection** buttons (Origin/Orientation/Scale) align from selected viewer locators — see Recipe 2. Ground Plane: Color, Size, Subdivision Level, Wireframe, Line Thickness, Offset (along Y). **Export** button builds Camera 3D (+ image plane), Point Cloud 3D, Shape 3D ground plane, Merge 3D, Renderer 3D; **Update Previous Export** rewrites those nodes after re-solving (manual unless **Automatically Update Previous Export After Solves** is on); **Export Options** checklist (Camera/Point Cloud/Ground Plane/Renderer/Lens Distortion/Enable Image Plane); **Animation** menu picks whether Camera or Point Cloud carries the keyframed motion.
- Gotchas: repeat-solve workflow is Recipe 1; false tracks (moving objects, reflections, parallax "moiré") are the top thing to hunt down; seed frames should share many tracks but be far apart in angle; after export, further 3D Scene Transform edits need a manual **Update Previous Export** click.

### Planar Tracker (PTRA)
Automates keyframing a rectangular/planar surface's perspective distortion over time (e.g. replacing a moving license plate or road sign) so a corner-pin match doesn't need manual per-frame keying. (p. 1589)
- Inputs: **Background** (orange, required); **Corner Pin 1, 2...** (green, Corner Pin mode only, add via +/-); **Occlusion Mask** (white); **Effect Mask** (blue).
- Saves the final Track/Stable Track splines (4x4 matrices) but **not** individual point trackers — these vanish from the viewer on reload, autosave recovery of an in-progress track is unreliable, and file size/load stay small. Finish planar tracking in one session (p. 1589).
- **Operation Mode** (mutually exclusive): **Track** (the only mode that runs the tracker); **Steady** (locks pattern motionless — QA, or to "lock" an effect like paint before un-steadying); **Corner Pin** (warps a connected foreground to match, merges over footage); **Stabilize** (smooths, doesn't remove, translation/rotation/scale over time).
- Track mode: **Reference Time** (frame the pattern is drawn on; can't change later without destroying tracking data). **Pattern Polygon** — draw on the reference frame; as large/in-frame/unoccluded/undistorted as possible; too few pixels/features causes jitter/wobble/slippage. **Tracker**: **Point** (small-pattern tracking, auto-builds its own occlusion mask, green=trusted/red=rejected in viewer, less artist effort) vs **Hybrid Point/Area** (tracks all pixels, more accurate/less wobble, slower, needs a manual occlusion mask) — try Point first, fall back to Hybrid. **Motion Type**: Translation < Translation+Rotation < +Scale (TRS) < Affine (+skew) < Perspective (most general); default to **Perspective**, drop to a simpler model only if the pattern is small/low-feature or points cluster on one side. **Output**: Background / Background-Preprocessed (useful for picking Track Channel) / Mask / Mask Over Background. **Track Channel**: R/G/B/luma. **Tracking Controls**: Track to Start/End, Step Prev/Next, Stop, Trim to Start/End, Delete. **Create Planar Transform** button hands off the tracking data to a portable node (Recipe 3).
- Steady mode: **Steady Time** (usually = reference frame); **Invert Steady Transform** (two Planar Trackers back-to-back, 2nd inverted, restores the original — used to lock an effect in between, Recipe 4); **Clipping Mode**: Domain (keeps off-frame pixels for a downstream un-steady pass) vs Frame (discards).
- Corner Pin mode: track → switch mode → connect texture to Corner Pin 1 → drag corners (Show Grid helps) → review. **Merge Mode**: BG only/FG only/FG over BG/BG over FG (shared across pins). Each pin: Enable, Show Grid, Merge Options, Reference Time Positions (hand-animatable to fix an imperfect track).
- Stabilize mode: track → switch mode → set **Parameters to Smooth** (X/Y Translation, Rotation, Scale) and **Smoothing Radius (Frames)** → **Compute Stabilization** → handle edges via **Frame Mode**: Full / **Crop** (**Auto Crop** picks the largest edge-clean centered pixel-aligned window, output shrinks, no resample) / **Zoom** (**Auto Zoom** scales up to cover edges, causes resample/slight softening) — both expose manual X/Y Offset + Scale. **Smoothing Window**: Box or Gaussian. Gotcha: it stabilizes the *pattern's* motion, not necessarily "the camera" — e.g. tracking a moving truck while panning alongside it smooths the combined motion; pick a fixed-object pattern (ground, building) to isolate camera motion only.
- Gotchas: knowing when to fall back to the Tracker node or manual keyframing is part of using this well — not a 100% solution; lens distortion in source footage directly causes slide/wobble, remove it first; with Hybrid, supply an occlusion mask for occluders; with Point, try without a mask first.

### Surface Tracker (SFt)
Tracks and warps a texture/effect onto a **flexible/deformable** surface (cloth, skin) so folds/deformation match realistically — unlike Planar Tracker, which assumes rigidity. (p. 1599)
- Inputs: **Input** (yellow, required); **Overlay** (green, image/video/node-tree to composite); **Occlusion Mask** (pink); **Effect Mask** (blue, applied after processing).
- Strict left-to-right workflow across four tabs: **Bounds → Mesh → Track → Result**, each showing **Tracked Range**; changing Bounds/Mesh resets existing tracking data.
- Bounds: click ≥3 points on the surface itself (not object edges/background) to form a boundary polygon; **+ Bound** adds another (joins into one shape, same surface only — use separate node instances for separate surfaces); **+ Hole** excludes a sub-region (e.g. eyes/mouth on a face, which deform too fast to track); **Delete** (not undoable), **Clear All**.
- Mesh: **Regenerate Mesh** rebuilds at current frame, discarding manual edits. **Point Locations**: **Automatic** (best in most cases) with **Point Number Limit** / **Minimum Point Spacing**, or **Uniform** (regular grid, may beat Automatic on highly detailed surfaces) with **Horizontal/Vertical Spacing**. Manual: drag points, Cmd+drag-select multiple, Option-click removes a point; points can't be added/removed once tracking starts (reset first). Rule of thumb: >5 points inside the boundary is usually enough; avoid points on smooth/low-detail areas. Low-contrast/HDR/log footage: temporarily add a Brightness/Contrast node before tracking, disable it after.
- Track: **Go to Start/End**; **Tracking Direction Controls** (Track Backwards, Backwards One Frame, Pause, Forwards Then Reverse, Forwards One Frame, Forwards); **Trimming** (Remove Before/At/After This Frame; **Track From Last Known Match** re-links across a cleaned-up gap). **Motion Range** (search distance — raise if fast motion is lost); **Mesh Rigidity** (lower = more flexible, best for noise-free/smooth warping; higher = stiffer); **Quality** (Faster while iterating, Better for final). **Interaction Overlays**: Show / Hide on Drag / Hide. Editing mesh points at one frame affects only that frame directly but reshapes neighboring *interpolated* frames. Gotcha: source clip frame rate ≠ timeline rate can make tracking stutter — bake retiming first via Edit page right-click > Render In Place (p. 1606).
- Result: **Output** — Warp Input 2 Onto 1 / Warp Input 2 Onto Blank (warped overlay+alpha only) / Warp Input 1's Alpha / Create Mesh Alpha Mask (ignores all inputs) / **Stabilize-Warp Input 1** (inverse-warps to reference frame, freezing the region for painting/grading) paired with **Rewarp Stabilized Clip** (re-applies motion after edits — standard de-warp/fix/re-warp pair). **Overlay/Alpha Source**: First Frame / Reference Frame / Each Frame (needed for animated overlays or re-warp). **Contract/Expand** + **Softness** (expanded area is not itself tracked). **Motion Blur** slider. **Overlay Placement**: Go To Reference / Set to Current / Reference Frame; **Positioning**: Sliders / Interactive Canvas (9-region drag grid) / Interactive Pins (1 pin=position, 2=+scale/rotate, 3=+perspective, up to 4 for full corner-pin distortion). **Compositing**: Composite Type (blend mode) + Opacity.

### Tracker (Tra)
Detects/follows pixel patterns to drive other nodes' parameters, stabilize footage, match-move a foreground, or corner/perspective-position. (p. 1608)
- Inputs: **Background** (orange, required); **Foreground** (green, optional — merged per chosen Operation); **Effect Mask** (blue).
- Usage: **inline** (Operation = Match Move stabilizes/match-moves directly) or **branched off** (not connected downstream; data published via **Connect To**). Can fully replace a Merge node for foreground match-moving.
- **IntelliTrack** (DaVinci Neural Engine, AI-based) is now the default — more precise/robust than the legacy tracker, especially through brief occlusions; no extra input beyond placing the crosshair and pressing a track-direction button. Legacy algorithm still available via the **Point** button (p. 1609-1610).
- Trackers tab: Track buttons (Reverse, Reverse From Current, Stop/Esc, Forward From Current, Forward); Trim to Start/End, Delete all. **Frames Per Point** (keyframe density, default 1/every frame; field-rendered footage: set **2** to avoid field jitter, p. 1613). **Adaptive [Point Only]**: None / Every Frame (reacquires each frame, compensates gradual lighting drift) / Best Match (reacquires only within **Match Tolerance**, avoids drift from transient artifacts like a shadow). **Path Center**: Pattern Center (replaces path) vs Track Center (append) (appends/offsets onto existing path — for when the original pattern exits frame/gets occluded; best if the new pattern sits near the old one, avoiding parallax/lens mismatch). **Tracker List** states: **Enabled** (black checkbox, re-tracks, available downstream), **Suspended** (white circle, locked, data still available for Match Move/Corner/Perspective), **Disabled** (clear, no path, unavailable). **Show**: Selected Tracker Details vs All Trackers. Pattern display: left = original pattern, right = live/accumulated Flipbook; confidence bar green/yellow/red. **Tracker Sizes**: Pattern/Search Width+Height. **Tracked Center** (right-click > Remove Path). **X/Y Offset** — track a reliable feature while the *published* path targets the actual (less trackable) point; adjustable in-viewer via the Offsets toolbar button.
- Operation tab: **Operation**: None (path only) / **Match Move** (stabilize BG, or match-move a connected FG; ≥1 pattern for position, ≥2 for scale/rotation) / **Corner Positioning** (tracks 4 corners, replaces contents — needs 4 patterns, auto-adds) / **Perspective Positioning** (inverse — maps 4 trackers to the 4 image corners to remove perspective; also needs/auto-adds 4). **Merge**: BG Only / FG Only / FG Over BG / BG Over FG, with standard **Apply Mode** set (Normal, Screen, Dissolve, Multiply, Overlay, Soft Light, Hard Light, Color Dodge, Color Burn, Darken, Lighten, Difference, Exclusion, Hue, Saturation, Color, Luminosity — Porter/Duff math identical to the Merge node) and, for Normal/Screen, an **Operator** menu (Over, In, Held Out, ATop, XOr; swap FG/BG for Under/In/Held In/Below) plus **Subtractive/Additive** slider (Additive assumes premultiplied FG). **Filter Method (Match Move)** — see Mental Model. **Edges**: Black Edges/Wrap/Duplicate/Mirror. **Position/Rotation/Scaling** checkboxes (Match Move) pick corrected components. **Flatten Transformation (Match Move)**. **Mapping Type (Corner Positioning)**: Bi-Linear (legacy) vs **Perspective** (preferred). **Corner Selector** (Corner/Perspective) assigns >4 patterns to the 4 corners; **Rotate CW/CCW** buttons rotate FG 90° first. **Stabilize Settings**: Stable Position X/Y always published, even if Operation ≠ Match Move. **Pivot Type**: Tracker Average / Selected Tracker / Manual. **Reference Time**: Select Time / Start / **Start and End** (uniquely: smooths motion between the two rather than locking to one snapshot, with a **Reference Intermediate Points** control) / End / Custom Time (Set+Go).
- Gotchas: no limit on trackers per node or patterns per tracker. Can run as a node or as a **Modifier** (Modifiers tab) attached to any parameter — Modifier form tracks only one pattern but can source its image from anywhere in the comp, good for a quick one-off position track. Spline Editor shows one displacement path by default; Preferences > Globals > Splines to see split X/Y paths instead.

### Common Controls — Tracking & Transform Settings tab
Identical family on every node in both categories: **Blend** (0.0 bypasses the tool; **Process When Blend Is 0.0** forces processing anyway, e.g. for scripted side effects); **Red/Green/Blue/Alpha** channel buttons (deselecting one copies that channel from input back over the result post-process; some tools instead skip processing that channel and duplicate these buttons on the Controls tab); **Apply Mask Inverted**; **Multiply by Mask** (unmasked pixels → black/transparent); **Use Object/Use Material** checkboxes (mask via EXR Object ID/Material ID channels) + **Correct Edges** (cleans multi-object edge aliasing via Coverage/Background Color channels) + **Object ID/Material ID** sliders (Sample button picks from viewer); **Motion Blur** group — Motion Blur toggle, **Quality** (samples each side of motion), **Shutter Angle** (360 = one full-frame-exposure equivalent), **Center Bias** (motion-trail looks), **Sample Spread** (sample weighting/brightness); **Use GPU** (Disable/Enabled/Auto); **Hide Incoming Connections** (drag a node into the emptied field to hide its line; reappears if re-selected in the tree); **Comments** (red square/bubble icon + tooltip); **Scripts** (three fields, run on render).

## Transform Nodes

### Camera Shake (CSh)
Simulates organic-to-mechanical camera shake (distinct from the Shake Modifier, which randomizes a numeric parameter value). Concatenates with adjacent transform nodes. (p. 1628)
- Inputs: **Input** (orange, required); **Effect Mask** (blue, applied after processing).
- Key controls: **Deviation X/Y** (0.0-1.0; 1.0 = shake reaches anywhere in image); **Rotation Deviation** (0.0-1.0); **Randomness** (higher = more irregular); **Overall Strength** (0-1 blend/amplitude over everything else); **Speed**; **Frequency Method**: Sine / Rectified Sine / Square Wave (more mechanical). **Filter Method**/**Window Method** — see Mental Model. **Edges**: Canvas/Wrap/Duplicate/Mirror. **Invert Transform** (undo an upstream Camera Shake exactly). **Flatten Transform** (stop concatenating downstream).

### Crop (Crp)
Cuts out or offsets a portion of an image — **changes resolution**; avoid animating. (p. 1631)
- Inputs: **Input** (orange, required).
- Controls tab: **Offset X/Y** (px; pushes image off-frame); **Size X/Y** (px, sets output resolution); **Keep Aspect**; **Keep Centered** (auto-adjusts offset, crop then driven by Size or the viewer's Allow Box Selection tool); **Reset Size/Offset**; **Change Pixel Aspect**; **Clipping Mode**: **Frame** (default — DoD forced to full frame, beyond-upstream-DoD area is black/transparent), **Domain** (respects upstream DoD, can clip badly with large-filter downstream nodes), **None** (no source clipping; out-of-DoD data is black/transparent).
- Auto Crop tab: pick **RGBA channels** to examine, click **Auto Crop** to detect background color and crop each side to the first differing pixel (writes into Controls tab).
- Viewer shortcut: enable **Allow Box Selection** (top-left) with Crop viewed, drag to crop interactively.

### DVE (DVE)
3D-style image transform (rotation, perspective, Z move) modeled on tape-based online-suite DVEs, definable axis. (p. 1634)
- Inputs: **Input** (orange, required); **DVE Mask** (white — masks the image *before* the transform); **Effect Mask** (blue, standard post-process mask).
- Controls tab: **Pivot X/Y/Z** (default 0.5, 0.5, 0); **Rotation Order**; **XYZ Rotation**; **Center X/Y** (default 0.5, 0.5); **Z Move** (zoom along Z); **Perspective** (adds FOV-style perspective on X/Y rotation).
- Masking tab (pre-transform, unlike a normal effect mask): **Black Background** (erase outside mask, post-transform); **Fill Black** (erase inside mask, pre-transform, cutting it out of source); both on = only the masked+transformed region shows. **Alpha Mode**: Ignore Alpha (masked areas forced opaque) / Subtractive / Additive (Additive for premultiplied FG, Subtractive for non-premultiplied).

### Letterbox (LBX)
Adapts an image to a different frame size/aspect (e.g. film → HD), adding bars/pillars — **changes resolution**; avoid animating. (p. 1637)
- Inputs: **Input** (orange, required).
- Key controls: **Width/Height** (px; right-click for Select Frame Format presets); **Auto Resolution** (syncs to Preferences or Resolve Timeline resolution); **Pixel Aspect X/Y**; **Center X/Y** (relevant only in Pan-and-Scan); **Mode**: **Letterbox/Envelope** (corrects aspect, resizes to match width) vs **Pan-and-Scan** (corrects aspect, resizes to match height; if result is wider than target, Center animates the visible crop). **Filter Method**/**Window Method** — see Mental Model.

### Planar Transform (PXF)
Applies a Planar Tracker's solved perspective distortion to any masked image/mask without needing the tracker node itself in the tree — the standard hand-off artifact for tracker-assisted rotoscoping/match moves (Recipe 3). (p. 1640)
- Inputs: **Image Input** (orange, required); **Effect Mask** (blue).
- Key controls: **Reference Time** (frame the source pattern came from); **Right-Click Here for Track Spline** — the 4x4-matrix spline, *shared* with the originating Planar Tracker, so re-tracking there auto-updates this node. Once created, the source Planar Tracker is no longer needed in the tree.

### Resize (Rsz)
Increases/decreases image resolution (e.g. film → video) — **changes resolution**; avoid animating. (p. 1642)
- Inputs: **Input** (orange, required).
- Key controls: **Width/Height** (px, right-click presets); **Auto Resolution**; **Reset Size**; **Keep Frame Aspect**; **Only Use Filter in HiQ** (otherwise fast Nearest Neighbor is used on non-HiQ renders; disable to force the chosen filter everywhere); **Change Pixel Aspect**. **Filter Method**/**Window Method** — see Mental Model.

### Scale (SCL)
Same job as Resize but expressed as a **relative multiplier** rather than exact target dimensions — **changes resolution**; avoid animating. (p. 1645)
- Inputs: **Input** (orange, required).
- Key controls: **Lock X/Y** (single Size slider vs independent X/Y); **Size** (1.0 = no change, 2.0 = double, 0.5 = half); **Only Use Filter in HiQ**; **Change Pixel Aspect**. **Filter Method**/**Window Method** — see Mental Model.

### Transform (XF)
Everyday 2D move/scale/rotate/flip tool. **Does not change resolution** — the default choice for animated scale/move/rotate. Concatenates with adjacent transform nodes. (p. 1648)
- Inputs: **Input** (orange, required); **Effect Mask** (blue).
- Key controls: **Center X/Y** (default 0.5, 0.5; shown value = normalized × Reference Size); **Pivot X/Y** (default 0.5, 0.5); **Use Size and Aspect** toggles independent X/Y Size vs Size+Aspect pair; **Size** (0-5 in UI, any >0 via edit box); **Aspect** (>1.0 stretches X, 0-1.0 stretches Y; Use Size and Aspect only); **Angle** (+ = counterclockwise); **Flip Horizontally/Vertically**; **Edges**: Canvas (Set Canvas Color node sets the color) / Wrap (seamless pannable backgrounds) / Duplicate / Mirror. **Filter Method**/**Window Method** — see Mental Model. **Invert Transform** (typical use: reintroduce motion into a stabilized image via a connected tracker). **Flatten Transform** (stops concatenating downstream only). **Reference Size**: display-only convenience — setting **Reference Width/Height** re-shows Center in pixel units (100x100 image: 0.5,0.5 shows as 50,50; +5px right = 55,50) without changing the stored/scripted/published normalized value. **Auto Resolution** syncs Reference Width/Height to current frame format/timeline resolution.

### Common Controls — Transform Settings tab
Identical to the Tracking-nodes Settings tab (see above) — Blend, Process When Blend Is 0.0, RGBA selector, Apply Mask Inverted, Multiply by Mask, Use Object/Material + Correct Edges + ID sliders, Motion Blur group, Use GPU, Hide Incoming Connections, Comments, Scripts. Present even on third-party Transform-category plugin tools (p. 1653).
